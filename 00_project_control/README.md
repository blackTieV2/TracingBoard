# Tracing Board Project Control

This folder controls the build and governance of tracingboard.org.

## Purpose

Tracing Board is being rebuilt from a legacy/static GitHub-hosted resource into a modern Masonic learning, discussion, and publishing platform.

## Operating Model

- `tracingboard.org` is the public brand and editorial front door.
- `community.tracingboard.org` is the planned community and discussion platform.
- GitHub is the source of truth.
- Lovable may be used for rapid front-end design.
- Codex may be used for engineering, review, refactoring, deployment, and hardening.
- Discourse is the preferred mature community/forum/Q&A engine.
- The production public platform should be cloud-hosted, not hosted from Layer-8 Labs.

## Build Principle

Do not build a custom forum from scratch.

Use proven platforms for authentication, moderation, notifications, email, and community management.
